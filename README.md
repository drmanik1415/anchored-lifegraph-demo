# Anchored — LifeGraph (UAE Fictional Demo)

A small Streamlit app adapted from the standalone Colab notebook. It demonstrates a fictional memory tree, documented retrieval, absence handling, simulated role access, and audit entries.

## Deploy
1. Create a GitHub repository (e.g. `anchored-lifegraph-demo`).
2. Upload `app.py` and `requirements.txt` to the repository root. (README.md optional.)
3. Visit https://share.streamlit.io and select **Create app** → existing app/repository.
4. Select your GitHub repository, branch `main`, and main file `app.py`.
5. Click **Deploy**. Share the URL ending in `.streamlit.app`.

No Colab server, tunneling, or external dataset is needed. Runs with `streamlit run app.py` locally.

**Important:** All data are fictional. Permissions are simulated and are not an identity check. Never upload patient or family records to a public demonstration.
